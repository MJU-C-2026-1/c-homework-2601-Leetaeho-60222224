# 💻 [2026-01] 나만의 C언어 소프트웨어 개발 프로젝트

## 1. 시나리오 제목
점심 식단 칼로리 계산기

<br>


## 2. 시나리오 (5~10줄)
 이 프로그램은 다이어트와 건강 관리를 위해 매일 점심으로 먹은 음식의 영양성분(탄수화물, 단백질, 지방)을 입력받아 총 섭취 칼로리를 계산해 주는 시스템입니다.
 사용자가 오늘 먹은 음식의 카테고리와 탄수화물, 단백질, 지방의 그램 수를 입력하면, 영양학 공식(탄/단 = 4ckal, 지 = 9kcal)을 적용하여총 섭취 칼로리를 산출합니다.

학기가 진행될수록 여러개의 메뉴를 입력받고, 일주일 치 식단 기록과 평균 칼로리를 관리하는 프로그램으로 발전시킬 계획입니다.

<br>


## 3. 예상 기능 및 메뉴 (최소 5개)
1. 점심 식단 영양성분 입력
2. 총 섭취 칼로리 계산 및 출력
3. 칼로리 초과 여부 경고 알림
4. 식단 기록 추가 및 종료 메뉴
5. 일주일치 평균 칼로리 통계

<br>

## 🟦 [1차 과제: V1.0] 기초 뼈대 구축 (입출력과 변수)
### **✨V1.0 개발 내용:**
    사용자로부터 오늘 멱은 점심 메뉴의 카테고리, 탄수화물, 단백질, 지방의 섭취량을 입력받아 총 섭취 칼로리를 계산하여 출력합니다.
    메뉴의 이니셜, 탄수화물 및 단백질 섭취량(정수형), 지방의 섭취량(실수형)을 입력받는 입출력 화면을 구현합니다.
    사칙연산을 활용해 영양학 공식(탄수화물4, 단백질4, 지방9)을 적용하여 총 섭취 칼로리를 산출하고 깔끔하게 출력합니다.
    
### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:** C언어 과제와 관련해서 식사 메뉴를 추천해주는 프로그램 기획 요청.
    * **적용 내용:** 메뉴를 추천해주는 로직은 조건문 사용이 불가피 → AI와 논의를 통해, 순차구조(입력→연산→출력) 만으로도 동작 가능한 계산기 형태로 변경.
      
 2. **내용 2**
    * **프롬프트 요약:** "1차 과제 필수 요건(변수 5개, 자료형 3개 이상)을 충족하기 칼로리 계산기 작성 문의
    * **적용 내용:** 단순히 '총 칼로리' 변수 하나만 입력받는 대신, 실제 영양성분 데이터의 특성을 반영하여 총 5개의 변수를 설정하고 3가지 자료형을 분리함.
    * 문자형 - 1개(메뉴 카테고리 식별)
    * 정수형 - 2개(일반적으로 대략적인 정수 단위로 표기되는 탄수화물/단백질 섭취량)
    * 실수형 - 2개(지방은 1g당 9kcal로 칼로리가 높아 소수점 단위의 측정이 필요하므로 실수형으로 분리하였고, 이에 따라 산출되는 총 칼로리 역시 실수형으로 설정)
    
### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:** 지방과 총 칼로리 출력시 소수점이 6자리까지 길게 나와 가독성이 떨어져 수정하는 과정에서 숫자 1 대신 알파벳 l을 사용하여 값이 의도치 않게 반올림 되거나 문법 오류가 발생함
     * **해결:** 알파벳 l을 숫자 1로 올바르게 고친 %1f를 사적용하여 영양성분표처럼 소수점 첫째 자리까지만 깔끔하고 정확하게 출력되도록 개선함
  2. **문제 2:** 출력 단위 중복 표기(g kcal) 및 변수명 스펠링 오류
     * **해결:** 칼로리 출력 부분의 불필요한 'g' 단위를 삭제하 출력단위를 수정하고, 오타가 난 변수명을 수정하였음

### **🤖 AI 파트너십 과정**
 1. **내용 1**
    * **프롬프트 요약:** 단순 칼로리 계산을 넘어, 탄단지 각각의 상태를 확인하고 동시에 여러 조언을 해주는 피드백 시스템 구현에 대한 방법 논의
    * **적용 내용:** 하나의 조건만 만족하면 종료되는 else if 대신 if를 여러번 배치하여 설계함.
    
### **🛠️ Troubleshooting & 기술 회고:**
  1. **문제 1:** 비율 검사를 if ~else 구조로 작성하여, 처음 조건(예: 탄수화물 초과)만 만족하면 나머지 조건(단백질, 지방)은 검사를 하지 않고 조건문을 완료하는 오류가 발생함
     * **해결:** else if를 없애고 각각을 if문 3개로 만들어 전체를 출력하도록 수정함.
  2. **문제 2:** C언어의 prinft 함수에서 비율을 출력하기 위해 %.1f%라고 작성하면, %를 새로운 형식 지정자의 시작으로 오해하여 오류가 발생  
     * **해결:** print문 안에서 순수한 문자로 퍼센트 기호를 화면에 보여주고 싶을때는 %%로 써야한다는 것을 알고 사용함.
